# For Riya — A Year of Us

A complete static anniversary website, including photos and audio. No install or build step is required.

## Put it on GitHub
1. Extract this ZIP.
2. Create a GitHub repository and upload the extracted files and the assets folder. Keep index.html at the repository root, not inside another folder.
3. In the repository, open Settings > Pages.
4. Select Deploy from a branch, choose main and / (root), and save.
5. GitHub Pages will display the website link once deployment finishes.

## Edit the website
- story.js: memory titles and memos, revealing cards, and anniversary letter.
- memory-photos.js: memory photos and captions.
- index.html: main page text and sections, including the gift code.
- style.css and water-story.css: appearance and responsive layouts.
- app.js: animations and interactive behavior.
- assets/: photos, audio, backgrounds, and other media.

This archive contains personal photos, messages, and the redeemable gift code. A public repository exposes these files, including the code underneath the scratch effect.
